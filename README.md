# MarketConsult - Лендинг консалтинговой компании

Одностраничный лендинг (SPA) для консалтинговой компании, специализирующейся на помощи продавцам на маркетплейсах. Проект разработан с использованием HTML, SCSS и Vanilla JavaScript с применением Vite в качестве сборщика.

## Особенности проекта

- Модульная компонентная структура
- Использование методологии БЭМ для именования классов
- Адаптивный дизайн для всех устройств
- Система адаптивных изображений (автоматическое управление отображением на разных устройствах)
- Оптимизированная производительность
- Плавная навигация по якорным ссылкам
- Валидация форм на стороне клиента
- Анимации и интерактивные элементы

## Структура проекта

```
├── src/
│   ├── assets/           # Статические ресурсы (изображения, шрифты)
│   ├── components/       # Компоненты страницы
│   │   ├── Header/       # Шапка сайта
│   │   ├── Hero/         # Главный баннер
│   │   ├── About/        # О компании
│   │   ├── Services/     # Услуги
│   │   ├── Cases/        # Кейсы
│   │   ├── CTA/          # Призыв к действию
│   │   ├── ContactForm/  # Форма обратной связи
│   │   ├── Footer/       # Подвал сайта
│   │   └── utils/        # Утилиты (включая адаптивные изображения)
│   ├── styles/           # Глобальные стили
│   │   ├── _variables.scss  # Переменные SCSS
│   │   ├── _mixins.scss     # Миксины SCSS
│   │   └── main.scss        # Основной файл стилей
│   └── main.js           # Точка входа JavaScript
├── index.html           # Основной HTML файл
├── vite.config.js       # Конфигурация Vite
└── package.json         # Зависимости проекта
```

## Технологии

- HTML5
- SCSS (с использованием переменных, миксинов и вложенности)
- Vanilla JavaScript (ES6+)
- Vite (сборка и разработка)
- Smooth Scroll (плавная прокрутка)
- Axios (для работы с API, если потребуется)

## Требования

- Node.js 14.x или выше
- npm 6.x или выше

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone [URL репозитория]
cd [название папки проекта]
```

2. Установить зависимости:
```bash
npm install
```

3. Запустить сервер разработки:
```bash
npm run dev
```

4. Открыть в браузере:
```
http://localhost:3000
```

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут доступны в директории `dist/`.

## Предпросмотр сборки

```bash
npm run preview
```
